About

Easy Icons lets you unlock specific Geometry Dash icons quickly and easily.

Requirements

  • Geometry Dash 2.207+
  • Latest Geode version
  • Windows

  • Linux

Installation

  1. Download the mod.
  2. Open Geode.
  3. Install the .geode file.
  4. Restart the game.
