About

Easy Icons is a lightweight Geode mod that lets you unlock specific Geometry Dash icons quickly and easily. Simply choose the icons you want and enjoy a faster customization experience.

Requirements

  • Geometry Dash 2.207+
  • Latest version of Geode
  • Windows or Android

Installation

  1. Download the latest release.
  2. Open Geode.
  3. Install the mod.
  4. Restart the game.
